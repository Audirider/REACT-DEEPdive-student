## 🎤 PRESENTATION FORMAT (10 min each)

### Structure:
1. **Introduction** (1 min) — Name, project name, tagline
2. **Live Demo** (4 min) — Walk through features at the live URL
3. **Code Walkthrough** (3 min) — Component tree, favorite code snippet
4. **Challenges & Learnings** (1 min) — What was hardest? What did you learn?
5. **Q&A** (1 min) — Class questions

### Demo Flow Suggestions:
- Add a new task → show it appears
- Toggle complete → show visual change
- Filter tasks → show filtering works
- Delete a task → show removal
- Show persistence → refresh page, data still there
- Show responsive → resize browser
