## 🎯 OBJECTIVE

Build a simple blog application with React Router featuring multiple pages, navigation, and dynamic post routes.

---

## 📋 REQUIREMENTS

- [ ] At least 4 routes: Home, Blog List, Blog Post (dynamic), About
- [ ] Navigation bar with `NavLink` (active state styling)
- [ ] Blog list page showing all post titles and previews
- [ ] Dynamic route `/posts/:id` for individual blog posts
- [ ] 404 Not Found page
- [ ] `useParams` to read post ID from URL
- [ ] `useNavigate` for "Back to Blog" button
- [ ] Sample data (at least 5 blog posts with title, body, author, date)

## ✅ ACCEPTANCE CRITERIA

- [ ] All routes work correctly
- [ ] NavLink highlights active page
- [ ] Dynamic post page loads correct content
- [ ] Back navigation works
- [ ] 404 page catches unknown URLs
- [ ] Professional layout and typography
